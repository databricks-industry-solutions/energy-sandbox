# Pipeline Commander — Pipeline Monitoring Command Center

A Streamlit application for real-time pipeline monitoring and operations management, built as a Databricks App.

## Features

- **Pipeline Visualization** — Real-time pipeline status dashboard
- **Anomaly Detection** — Pressure and flow anomaly monitoring
- **Operations Management** — Work order and maintenance tracking

## Prerequisites

- Databricks workspace with **Apps** enabled
- Databricks CLI installed and configured
